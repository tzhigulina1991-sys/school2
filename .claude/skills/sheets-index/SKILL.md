# Скилл: индексация Google Sheets (/sheets-index)

Когда пользователь вызывает `/sheets-index`, обойди все доступные Google Sheets через gws CLI и создай файл `sheets-index.md` в корне проекта.

## Когда перезапускать индекс

- Добавлена новая таблица в Drive
- Изменилась структура (новые вкладки, переименование колонок)
- Прошло более 14 дней с последней индексации
- Появились новые вопросы, которые индекс не покрывает

## Шаги

### 1. Получи список всех таблиц

```bash
~/bin/gws drive files list \
  --params '{"q":"mimeType=\"application/vnd.google-apps.spreadsheet\"","fields":"files(id,name,modifiedTime)","pageSize":100}'
```

Разбери JSON-ответ: для каждого файла извлеки `id`, `name`, `modifiedTime`.

### 2. Для каждой таблицы получи структуру вкладок

```bash
~/bin/gws sheets spreadsheets get \
  --params '{"spreadsheetId":"SHEET_ID","fields":"sheets(properties(sheetId,title,gridProperties))"}'
```

Из ответа извлеки для каждой вкладки: `sheetId` (GID), `title`, `rowCount`, `columnCount`.

### 3. Для каждой вкладки прочитай заголовки

Читай только первую строку — заголовки колонок:

```bash
~/bin/gws sheets spreadsheets values get \
  --params '{"spreadsheetId":"SHEET_ID","range":"SHEET_TITLE!A1:Z1"}'
```

Если вкладок много (>5) — читай только первые 3 и самые содержательные по названию (избегай «Лист1», «Sheet1», «Служебная»).

Для оценки количества строк читай первую колонку целиком и считай непустые значения:

```bash
~/bin/gws sheets spreadsheets values get \
  --params '{"spreadsheetId":"SHEET_ID","range":"SHEET_TITLE!A:A"}'
```

### 4. Сформируй sheets-index.md

Создай файл в корне проекта строго по шаблону:

```markdown
# Индекс Google Sheets

> Обновлён: YYYY-MM-DD. Таблиц: N.
> Для обновления запусти `/sheets-index`.

## Таблицы

### Название таблицы
- **ID:** `sheet_id`
- **Изменена:** YYYY-MM-DD
- **Вкладки:**
  - `Название вкладки` (GID: 123456, ~N строк) — колонки: Колонка1, Колонка2, ...
  - `Название вкладки 2` (GID: 789, ~N строк) — колонки: ...
- **Темы:** тема1, тема2, тема3

### Следующая таблица
...
```

Темы — ключевые понятия для поиска: имена людей (если встречаются в названии), процессы («оплата», «посещаемость», «ученики», «кураторы»), объекты («семья», «класс», «долг»).

### 5. Сохрани файл

Запиши `sheets-index.md` в корень проекта (Write).

Выведи итог: сколько таблиц и вкладок проиндексировано.

## Правила

- Названия колонок цитируй точно из первой строки
- Если таблица недоступна (403/404) — включи её с пометкой «нет доступа»
- Если первая строка пустая — пиши «заголовки не определены»
- GID = числовой sheetId из метаданных (не путай с индексом вкладки)
