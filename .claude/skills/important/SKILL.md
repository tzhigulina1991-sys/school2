# Скилл: еженедельный дайджест директора

Когда пользователь вызывает `/important`, собери еженедельный дайджест из Discord-каналов школы по критериям из `filter-criteria.md`.

## Шаги

### 1. Загрузи токен
Прочитай `DISCORD_TOKEN` из файла `.env` в рабочей директории.

### 2. Получи сообщения из каналов
Используй Discord API v10. Загрузи последние 100 сообщений из каждого канала:

| Канал | ID |
|-------|----|
| продажи | 1490709980351828079 |
| маркетинг | 1490709924370452500 |
| кураторы | 1490709891721986219 |
| техподдержка | 1490709961557278792 |
| general | 1490709645420007677 |

Запрос: `GET https://discord.com/api/v10/channels/{channel_id}/messages?limit=100`
Заголовок: `Authorization: Bot {DISCORD_TOKEN}`

Фильтруй сообщения за последние 7 дней. Системные сообщения (type != 0) пропускай.

### 3. Отфильтруй по критериям

**Включай:**
- `продажи` — только итоговые цифры (записи, план, конверсия). Пропускай детали сделок и переговоры между менеджерами
- `маркетинг` — метрики (заявки, конверсия, охват). Ставь флаг ⚠️ если цифра значительно ниже ожидаемой
- `кураторы` — проблемы требующие решения директора + значимые позитивные события с учениками. Пропускай доступы, методички, расписание
- **любой канал** — сообщения где команда явно эскалирует вопрос или не может решить самостоятельно

**Не включай:**
- Светские разговоры, еда, подарки, мерч, поздравления
- Решённые технические тикеты
- Промежуточные статусы («почти готово», «скину к обеду»)
- Рутинные операционные действия

### 4. Сформируй дайджест

Структура — разбивка по дням недели (пн–пт). Для каждого дня выводи только те блоки, по которым есть что сказать:

```
# Дайджест за неделю [дата – дата]

## Понедельник, [дата]
**Продажи:** ...
**Маркетинг:** ...
**Ученики:** ...
**Требует решения:** ...

## Вторник, [дата]
...
```

Блок «Требует решения директора» — если есть эскалации, выноси отдельно в конце дайджеста итоговым списком.

### 5. Правила оформления
- Коротко и по делу — весь дайджест читается за 5 минут
- Числа и факты, не пересказ переписки
- Если день пустой — не включай его
- Если данных за неделю нет — напиши об этом явно
