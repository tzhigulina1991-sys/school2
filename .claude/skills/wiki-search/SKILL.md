# Скилл: поиск по корпоративной вики (/wiki-search)

Когда пользователь вызывает `/wiki-search`, найди ответ на его вопрос в корпоративных документах.

## Входные данные

Вопрос передаётся как аргумент после `/wiki-search`. Например:
```
/wiki-search Какой срок возврата по Годовому тарифу?
```

## Шаги

### 1. Прочитай индекс

Прочитай файл `wiki-index.md` в корне проекта (Read).

Если файл не существует — предупреди пользователя: «Индекс вики не найден. Запусти `/wiki-index` для его создания.» — и выполни поиск напрямую через Grep по `wiki/` и `documents/`.

### 2. Найди релевантные документы по индексу

Из прочитанного индекса выбери документы, чьи **Темы** или **Краткое описание** пересекаются с вопросом пользователя. Учти синонимы:
- «возврат» → возврат, refund, вернуть, деньги
- «тариф» → тариф, тарифный, план
- «срок» → срок, дней, период, дата
- «к кому» / «контакт» → контакт, ответственность, Slack, менеджер, роль
- «продление» → продление, renewal, renewed
- «долг» / «просрочка» → overdue, задолженность, долг

Если по индексу ничего не найдено — используй Grep по `wiki/` как запасной вариант.

### 3. Прочитай отобранные документы

Прочитай (Read) только те файлы, которые отобраны на шаге 2. Не читай все подряд.

### 4. Разреши противоречия

Если два документа содержат разные данные по одному вопросу:
- Сравни даты документов (поле «Обновлён» или дата в тексте)
- Используй данные из более позднего документа
- В ответе укажи оба источника и отметь, какой приоритетнее

### 5. Сформируй ответ

Ответ строго по шаблону:

```
## Ответ

[Чёткий ответ на вопрос — 2–5 предложений или маркированный список]

---
📄 Источник: `имя-файла.md`, раздел «Заголовок раздела»
```

Если релевантная информация найдена в нескольких файлах — укажи все источники.

Если в вики нет ответа — напиши явно: «В корпоративной вики ответа не найдено» и предложи уточнить вопрос или обратиться к ответственному лицу (если известно из контекста).

## Правила

- Не додумывай и не дополняй информацию из вики своими знаниями
- Цитируй точные цифры, имена и теги так, как они записаны в документе
- Если документ содержит предупреждение (⚠️) — обязательно включи его в ответ
- Ответ должен читаться за 30 секунд
