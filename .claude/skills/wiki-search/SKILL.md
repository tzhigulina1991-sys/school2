# Скилл: поиск по корпоративной вики (/wiki-search)

Когда пользователь вызывает `/wiki-search`, найди ответ на его вопрос в корпоративных документах.

## Входные данные

Вопрос передаётся как аргумент после `/wiki-search`. Например:
```
/wiki-search Какой срок возврата по Годовому тарифу?
```

## Шаги

### 1. Определи ключевые слова из вопроса

Выдели 3–5 ключевых слова или фраз из вопроса пользователя. Учти синонимы:
- «возврат» → «возврат», «refund», «вернуть», «деньги»
- «тариф» → «тариф», «тарифный», «план»
- «срок» → «срок», «дней», «период»
- «контакт» / «к кому» → «контакт», «ответственность», «Slack», «менеджер»

### 2. Найди релевантные файлы

Используй инструмент Grep для поиска по директориям `wiki/` и `documents/` (если существуют) в рабочей директории проекта. Ищи каждое ключевое слово отдельно.

Затем прочитай (Read) все файлы, в которых найдены совпадения.

Если ни один файл не найден — сообщи об этом пользователю и предложи уточнить вопрос.

### 3. Извлеки релевантные разделы

Из прочитанных файлов выдели только те абзацы и разделы (заголовки `##`, `###`), которые отвечают на вопрос. Не копируй весь файл.

### 4. Сформируй ответ

Ответ строго по шаблону:

```
## Ответ

[Чёткий ответ на вопрос — 2–5 предложений или маркированный список]

---
📄 Источник: [название файла без пути], раздел «[заголовок раздела]»
```

Если релевантная информация найдена в нескольких файлах — укажи все источники.

Если в вики нет ответа — напиши явно: «В корпоративной вики ответа не найдено» и предложи к кому обратиться (если это известно из контекста).

## Правила

- Не додумывай и не дополняй информацию из вики своими знаниями
- Цитируй точные цифры и имена так, как они записаны в документе
- Если документ содержит предупреждение (⚠️) — обязательно включи его в ответ
- Ответ должен читаться за 30 секунд
