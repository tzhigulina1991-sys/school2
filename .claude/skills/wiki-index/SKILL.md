# Скилл: индексация корпоративной вики (/wiki-index)

Когда пользователь вызывает `/wiki-index`, обойди все документы в `wiki/` и `documents/` (если существует), и создай файл `wiki-index.md` в корне проекта.

## Когда перезапускать индекс

Перезапусти `/wiki-index` при любом из условий:
- Добавлен новый документ в `wiki/` или `documents/`
- Существующий документ существенно обновлён (новые разделы, изменились контакты, цифры)
- Удалён или переименован документ
- Прошло более 30 дней с даты последней индексации (см. поле «Обновлён» в `wiki-index.md`)

## Шаги

### 1. Найди все документы

Используй Glob для поиска всех `.md` файлов в `wiki/` и `documents/` (если существует).

Если ни одна директория не существует — сообщи об этом и завершись.

### 2. Прочитай каждый документ

Для каждого найденного файла:
- Прочитай полное содержимое (Read)
- Извлеки: заголовок (первый `#`), список тем (ключевые понятия из заголовков `##` и `###`), дату последнего изменения если указана в документе

### 3. Сформируй wiki-index.md

Создай файл `wiki-index.md` в корне проекта строго по шаблону:

```markdown
# Индекс корпоративной вики

> Обновлён: YYYY-MM-DD. Документов: N.
> Для обновления индекса запусти `/wiki-index`.

## Документы

### [Заголовок документа]
- **Файл:** `wiki/имя-файла.md`
- **Темы:** тема1, тема2, тема3, ...
- **Краткое описание:** одно предложение о чём документ

### [Следующий документ]
...
```

Темы — это ключевые понятия, по которым менеджер будет искать: конкретные названия (тарифов, процессов, имён), глаголы действия («возврат», «продление», «эскалация»), роли («финансовый менеджер», «куратор»).

### 4. Сохрани файл

Запиши `wiki-index.md` в корень проекта (Write).

Выведи подтверждение: сколько документов проиндексировано и путь к файлу.

## Правила

- Не сокращай и не перефразируй имена, цифры и термины из документов — копируй точно
- Если документ пустой или не содержит заголовков — включи его с пометкой «нет структуры»
- Темы пиши через запятую, строчными буквами, без точки в конце
