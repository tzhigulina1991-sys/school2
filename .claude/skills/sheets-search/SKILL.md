# Скилл: поиск по Google Sheets (/sheets-search)

Когда пользователь вызывает `/sheets-search`, найди ответ на вопрос в Google Sheets через индекс.

## Входные данные

Вопрос передаётся как аргумент:
```
/sheets-search Сколько у Ирины Комаровой учеников 9 класса?
```

## Шаги

### 1. Прочитай индекс

Прочитай `sheets-index.md` в корне проекта (Read).

Если файл не существует — предупреди: «Индекс не найден. Запусти `/sheets-index`.»

### 2. Найди релевантную таблицу и вкладку

По полям **Темы**, **Вкладки** и названию таблицы определи, какая таблица и вкладка содержит ответ. Учти синонимы:
- «ученик» → ученики, студент, учащийся, класс
- «семья» → семья, родитель, мама, папа, семей
- «ведёт» / «куратор» → куратор, менеджер, ответственный, классный руководитель
- «многодетная» → дети, детей, семья, кол-во детей
- «должник» / «оплата» → долг, оплата, задолженность

Если подходят несколько вкладок — выбери все и читай каждую.

### 3. Прочитай данные из найденной вкладки

Сначала прочитай заголовки (строка 1) для понимания структуры:
```bash
~/bin/gws sheets spreadsheets values get \
  --params '{"spreadsheetId":"SHEET_ID","range":"SHEET_TITLE!A1:Z1"}'
```

Затем прочитай данные порциями по 200 строк до исчерпания:
```bash
~/bin/gws sheets spreadsheets values get \
  --params '{"spreadsheetId":"SHEET_ID","range":"SHEET_TITLE!A1:Z200"}'
```

### 4. Найди ответ в данных

Ищи по ключевым словам из вопроса в нужных колонках. Фильтруй строки, считай количество, извлекай значения.

Запомни номера строк (row index, начиная с 1) для всех найденных записей — они нужны для ссылки.

### 5. Сформируй ответ

```
## Ответ

[Конкретный ответ — число, список, имя]

---
📊 Источник: «Название таблицы» → вкладка «Название вкладки»
🔗 https://docs.google.com/spreadsheets/d/{SHEET_ID}/edit?gid={GID}&range=A{N}:Z{N}
```

Если найдено несколько строк — ссылку дай на первую найденную запись, остальные перечисли в ответе.

Если ответ не найден — напиши явно и предложи уточнить или перезапустить `/sheets-index`.

## Правила

- Не додумывай данные — только то, что есть в ячейках
- Если колонка называется иначе, чем ожидаешь — ориентируйся по содержимому
- GID берётся из `sheets-index.md`, не из URL
- Номер строки N = индекс в массиве values + 1 (строка 1 = заголовок)
