Собери ежедневный дайджест из Discord-каналов школы по критериям из filter-criteria.md.

## Шаги

### 1. Загрузи токен
Прочитай DISCORD_TOKEN из файла .env в рабочей директории.

### 2. Получи сообщения из каналов
Используй Bash и curl с Discord API v10. Загрузи последние 100 сообщений из каждого канала:

- продажи: 1490709980351828079
- маркетинг: 1490709924370452500
- кураторы: 1490709891721986219
- техподдержка: 1490709961557278792
- general: 1490709645420007677

Запрос: GET https://discord.com/api/v10/channels/{channel_id}/messages?limit=100
Заголовок: Authorization: Bot {DISCORD_TOKEN}

Фильтруй сообщения за последние 24 часа. Системные сообщения (type != 0) пропускай.

### 3. Отфильтруй по критериям из filter-criteria.md

**Включай:**
- продажи — только итоговые цифры (записи, план, конверсия). Пропускай детали сделок
- маркетинг — метрики (заявки, конверсия, охват). Ставь флаг ⚠️ если цифра значительно ниже ожидаемой
- кураторы — проблемы требующие решения директора + значимые позитивные события. Пропускай доступы, методички, расписание
- любой канал — сообщения где команда эскалирует вопрос или не может решить самостоятельно

**Не включай:**
- Светские разговоры, еда, подарки, мерч
- Решённые технические тикеты
- Промежуточные статусы задач
- Рутинные операционные действия

### 4. Сформируй дайджест: 5–7 пунктов, 2 минуты чтения

Формат каждого пункта:
**[⚠️ или 🎉] Суть** — Автор в `#канал`: один факт.

Структура:

# Дайджест · [дата]

1. ⚠️/🎉 **Суть** — Автор в `#канал`: факт.
2. ...

**Продажи за день:** X записей, план Y из Z.

Пустые пункты не добавляй. Если данных за 24 часа нет — скажи об этом явно и возьми последние доступные сообщения.
